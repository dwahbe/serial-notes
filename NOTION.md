# Notion export

The Notion direct-send integration (issue #8) — the third `ExportTarget`, and the one direct-send target that delivers over the network instead of locally (opt-in, default off). The compact summary and the deferred post-meeting queue it rides live in [CLAUDE.md](CLAUDE.md) → Architecture; this file holds the full detail. App-side types are the `Notion*` files (see the Project map in CLAUDE.md); the site half lives in `site/src/pages/oauth/notion/` + `site/src/pages/api/notion/token.ts`.

Privacy copy stays matter-of-fact by Dylan's call: exports are user-chosen destinations (Apple Notes syncs via iCloud too), so "nothing leaves your Mac" claims stand and Notion is mentioned as a feature, not hedged everywhere. Credentials are loaded fresh at send time, with a send-time connected re-check (mirrors Bear's install re-check). **Availability = connected, not installed** — no `isInstalled` gate; the onboarding tile is always offered (SF-Symbol fallback icon when the desktop app is absent).

- **OAuth via the site proxy:** Notion has no PKCE, so the client secret lives in the site's server routes — `/oauth/notion/start` (holds client ID + the two-item byte-exact redirect-URI allowlist), static `/oauth/notion/callback` + `dev-callback` pages that bounce `?code&state` (and error exits) into `serialnotes://oauth/notion` (dev: `serialnotes-dev://`, stamped by `build-app.sh`'s dev block; handled via `kAEGetURL` in `AppDelegate` — `.onOpenURL` needs a live scene), and `POST /api/notion/token` (exchange/refresh/revoke with Basic auth; stores and logs nothing). The callback pages **must never let the code reach a beacon**: they opt out of the site's `<Analytics />` (Layout's `analytics={false}`) and their inline script scrubs the query via `history.replaceState` before anything else runs; every bounce panel carries a manual open-app button (some browsers block gesture-less custom-scheme navigation). Shared OAuth constants (redirect-URI allowlist, pinned token-endpoint version) live once in `site/src/lib/notionOAuth.ts` — both server routes import it. Env vars `NOTION_CLIENT_ID`/`NOTION_CLIENT_SECRET`. Only the handshake touches serialnotes.app; transcripts go app → `api.notion.com` directly (Markdown Content API, `Notion-Version: 2026-03-11` — raw `markdown` field). The connection requests **insert-content capability only**, and that grant does NOT get Notion's H1→title derivation (needs `insert_property`; confirmed live 2026-07-16 — pages arrived untitled) — so the client lifts the transcript's `# Meeting — …` H1 into an explicit `properties.title` at creation (an insert-content operation) and strips it from the body (`NotionAPIClient.titleAndBody`).
- **Credentials = one versioned Keychain record** (`NotionCredentialStore` actor, service scoped by bundle ID for dev/prod isolation), written atomically and only ever *complete*: connect finishes by creating the parentless workspace-level "Meeting Notes" destination page **before** anything persists, so quit-mid-flow leaves nothing and a reconnect can't inherit a stale destination. Disconnect = best-effort revoke (never skip the attempt — a local-only delete leaves the workspace authorized) → clear → toggle off.
- **Failure rules (`NotionAPIClient` actor):** 401 → **single-flight refresh** (Notion rotates refresh tokens; concurrent 401s share one in-flight task, credentials re-read after every await) → retry once; refresh rejection → `needsReconnect` badge in Settings, exports skip with a logged reason. Deleted destination self-heals (recreate, persist, retry once) — and "deleted" has TWO signatures: hard-deleted → 404, but **trashed → 400 `validation_error`** (Notion keeps archived pages ~30 days; confirmed live 2026-07-16), matched narrowly by `indicatesArchivedParent` (code + archive/trash message, parented creates only — under insert-only capability the parent can't be read to check its state). 429 honors `Retry-After` once. **Ambiguous transport failures are never retried** — no idempotency key exists, prefer under-delivery. 500 KB pre-flight body guard (Notion's request cap). All best-effort; `transcript.md` on disk stays the source of truth.
